# 2026-03-17 战斗文档拆分设计

## 目标

把 `docs/第一版文档/战斗.md` 从单一大型文档，拆分成 `总纲 + 功能子文档` 的结构，方便后续针对单一主题持续细化，降低讨论与收束时的混乱度。

## 拆分原则

- `战斗.md` 保留为 `总纲 + 导航页`
- 具体规则下沉到子文档
- 采用 `一处定义，别处极短摘要 + 关联引用` 的混合模式
- 每个子文档开头写清楚：`本文件负责什么`、`本文件不负责什么`、`关联规则去哪看`
- 当前任务先做结构拆分，不强行重写所有尚未完全收束的细节
