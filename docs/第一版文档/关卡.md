# 武侠零关卡

## 关卡设计目标

《武侠零》的关卡不是用来“塞内容”的，而是用来出题的。每个房间都应该像一道短、狠、清晰的战术题，让玩家在很短时间内判断、切入、破局、收刀。

## 房型基础

### 长廊房

特点：直线压迫强，适合做远程火线和枪卫正面封锁。

用途：训练玩家先杀远程、快速断火线。

### 庭院房

特点：空间开阔，可从多个方向切入。

用途：训练玩家自主选择路线，避免被包围。

### 楼阁房

特点：多层结构明显，垂直位移价值高。

用途：强化轻功、穿层追击和坠杀路线。

### 地牢房

特点：空间狭窄，容错低。

用途：让 `断息` 和精准站位成为关键。

### 宴厅房

特点：家具多、遮挡多、路线复杂。

用途：集中体现借物位移、屏风绕切和影踏高光。

### 追逐房

特点：玩家必须持续前进，不能长时间停顿。

用途：逼玩家在运动中判断优先级。

### 守关房

特点：敌人编组完整、没有明显软肋。

用途：检验玩家是否真正掌握了整套出题语言。

## 敌人和房间的搭配原则

- 弩手定义开场优先级
- 枪卫定义正面压力和路线限制
- 刀手负责形成速度感和压迫补位
- 重甲负责堵点和打断节奏
- 异士负责制造“必须换打法”的题

## 章节关卡递进

### 第一章

重点是基础长廊房、庭院房和简单守关房，让玩家学会先手与火线处理。

### 第二章

加入追逐房和更强的前后夹击，强调“边走边杀”。

### 第三章

开始大量使用宴厅房、楼阁房和复杂障碍空间，强调路线美感和临场修正。

### 第四章

让敌人站位更聪明、更懂主角套路，强化垂直联动和反制。

### 第五章

进入纪律化阵型阶段，强调守关房和编组完整度。

### 第六章

在高压条件下把所有房型都推到更高精度，逼玩家把全部技巧用到极致。

### 终章

房间数量减少，但质量和心理压力提升，每一间都像终局考题。

## 关卡质量标准

- 玩家进入房间 2 到 3 秒内就能看出最危险的点
- 每个房间至少有一个明确战术问题
- 房间要允许多条路线，但不能糊成一团
- 成功清房时必须有“打得漂亮”的成就感

## 第一版切片建议

最适合作为垂直切片的关卡段落是第三章的一小段，包括：

- 水巷码头：标准房
- 赌坊正厅：复杂房
- 杜见潮 Boss 战

因为这一段最能同时体现开放空间、复杂空间、人物复杂性和武侠辨识度。
