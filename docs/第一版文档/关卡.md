# 武侠零关卡

## 关卡设计目标

《武侠零》的关卡不是用来“塞内容”的，而是用来出题的。每个房间都应该像一道短、狠、清晰的战术题，让玩家在很短时间内判断、切入、破局、收刀。

## 房型基础

### 长廊房

特点：直线压迫强，适合做远程火线和枪卫正面封锁。

用途：训练玩家先杀远程、快速断火线。

### 庭院房

特点：空间开阔，可从多个方向切入。

用途：训练玩家自主选择路线，避免被包围。

### 楼阁房

特点：多层结构明显，垂直位移价值高。

用途：强化轻功、穿层追击和坠杀路线。

### 地牢房

特点：空间狭窄，容错低。

用途：让精准站位和短促换线成为关键。

### 宴厅房

特点：家具多、遮挡多、路线复杂。

用途：集中体现借物位移、屏风绕切和影踏高光。

### 追逐房

特点：玩家必须持续前进，不能长时间停顿。

用途：逼玩家在运动中判断优先级。

### 守关房

特点：敌人编组完整、没有明显软肋。

用途：检验玩家是否真正掌握了整套出题语言。

## 敌人和房间的搭配原则

- 弩手定义开场优先级
- 枪卫定义正面压力和路线限制
- 刀手负责形成速度感和压迫补位
- 重甲负责堵点和打断节奏
- 异士负责制造“必须换打法”的题

## 章节关卡递进

在章节层面，第一版更适合先统一一条 `章节节奏语法`，但不把每章做成完全一样的模板。

更合适的理解是：

- `教学期` 不急着强加压力
- `每学会一个关键技巧`，压力抬一小档
- `中间必须有熟悉房 / 自信房`
- `真正高压` 留给小 Boss 前、大围杀、或章节后段的变题房
- `环境 / 侧面信息 / 剧情` 要提前告诉玩家接下来会面对什么

如果压成一句话，就是：

`先让玩家学，接着让玩家稳，再让玩家惊，最后在关键节点把压力压满。`

这一条是 `章节设计思路`，不是死模板。

也就是说，每个章节都可以因为剧情、演出和战斗方式不同，而长出不同的局部曲线。比如：

- 某一章可能更重 `楼阁追压 + 垂直换线`
- 某一章可能更重 `长路追逐 + 边走边杀`
- 某一章甚至可以插入明确的特殊战斗段落，例如 `骑马战斗`

同理，章节内部也不必死守“只出现一个 Boss”：

- 有些章节可能只有一个 `章末 Boss`
- 有些章节也可能出现 `2 到 3 个小 Boss / 守关节点`

但不管局部形式怎么变，章节整体仍要服从上面的总方向，而不是想到什么玩法就往里塞。

### 章节语法怎么具体落地

#### 1. 每学会一个关键技巧，压力抬一小档

这里的“抬一小档”，不是简单把敌人数量往上堆，而是让：

- `敌人组合种类` 变多
- `关卡空间组合` 变复杂
- `击杀敌人需要的反应` 变高

也就是说，玩家刚学会一个技巧后，下一步不是立刻被同样内容重复轰炸，而是会遇到：

- 需要把这个新技巧和旧技巧一起用的房
- 敌人职责开始互相叠加的房
- 需要更快判断优先级、更快做出反应的房

这条规则的重点不是“越来越难”，而是：

`越来越要求玩家把刚学会的东西真的用出来。`

#### 2. 熟悉房 / 自信房

章节里必须穿插两种很重要的房：

- `熟悉房`
  配置接近教学房，或者只比教学房稍微难一点。
  它的作用是让玩家把刚学到的东西真正用顺，而不是刚学完立刻被更复杂的题打乱。

- `自信房`
  通常接在 `压力房` 后面。
  它的作用不是再拧紧，而是让玩家明确感到：

  `我确实学会了。`

所以这两类房的意义，不是拖节奏，而是给玩家建立：

- `熟悉感`
- `掌控感`
- `再往后继续学的信心`

### 第一章

重点是基础长廊房、庭院房和简单守关房，让玩家学会先手与火线处理。

### 第二章

加入追逐房和更强的前后夹击，强调“边走边杀”。

### 第三章

开始大量使用宴厅房、楼阁房和复杂障碍空间，强调路线美感和临场修正。

### 第四章

让敌人站位更聪明、更懂主角套路，强化垂直联动和反制。

### 第五章

进入纪律化阵型阶段，强调守关房和编组完整度。

### 第六章

在高压条件下把所有房型都推到更高精度，逼玩家把全部技巧用到极致。

### 终章

房间数量减少，但质量和心理压力提升，每一间都像终局考题。

## 关卡质量标准

- 玩家进入房间 2 到 3 秒内就能看出最危险的点
- 每个房间至少有一个明确战术问题
- 房间要允许多条路线，但不能糊成一团
- 成功清房时必须有“打得漂亮”的成就感

## 第一版切片建议

最适合作为垂直切片的关卡段落是第三章的一小段，包括：

- 水巷码头：标准房
- 赌坊正厅：复杂房
- 杜见潮 Boss 战

因为这一段最能同时体现开放空间、复杂空间、人物复杂性和武侠辨识度。
