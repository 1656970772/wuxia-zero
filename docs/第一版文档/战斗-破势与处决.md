# 战斗-破势与处决

## 文件说明

- 本文件负责：破势机制、爆头奖励、处决窗口、势反馈、调参与验收标准
- 本文件不负责：玩家动作定位、敌人 archetype 细节、Boss 个体风格
- 关联规则：攻击输入摘要见 `战斗-攻击.md`；Boss 个体设计见 `战斗-Boss设计.md`

## 九、破势机制

当前版本统一采用 `破势` 作为战斗推进核心，而不是传统磨血条。

### 9.1 先统一，再做差异

Boss 的表现方式可以不同，但底层阅读规则必须统一。

如果每个 Boss 都用完全不同的一套伤害规则，玩家会出现两个问题：

- 每到 Boss 就像在学一款新游戏
- 前面房间里练出来的经验，到了 Boss 那里不再成立

这样会伤到前面已经定下来的核心体验：

`我是一路拼着杀到这里的。`

因为如果 Boss 完全换规则，玩家的感觉就会从：

“我终于杀到你面前了”

变成：

“好，现在开始重新学教程。”

所以这一版先统一成一条母规则：

`Boss 默认不可被随便蹭死`
`玩家必须先创造破势 / 破绽`
`抓住破绽后才能造成真正有效的重创`
`重创积累到一定程度后进入斩决`

### 9.2 共通骨架

当前确认的 Boss 推进框架是：

`压势 -> 破势 -> 重创 -> 斩决`

不同 Boss 的压势方式、破势条件、破绽窗口、战斗气质都可以不同，但玩家必须始终知道自己在推进什么。

### 9.3 破势来源

目前已经确认的关键机制如下：

- `打中头部`：快速破势
- `敌人格挡`：也会破势
- `敌人闪避`：同样会破势

这意味着破势不是单纯打数值，而是不断拆对方的架子、逼对方交保命动作、逼对方失去从容。

### 9.4 为什么这套机制对

因为它能同时保住三件事：

- `爽感`
你打到头就是狠。
- `厮杀感`
不是随便蹭一下就赢。
- `策略感`
你在想“怎么让他失势”，不是单纯磨血。

这会自然形成一种非常武侠的逻辑：

不是“我砍你三刀你死”，而是：

- 我先逼你挡
- 再逼你退
- 再抢你半拍
- 最后一刀送进命门

### 9.5 破势在普通敌人身上怎么落地

普通敌人的破势机制，重点不是让玩家“读很多次”，而是让玩家在极短时间内感受到：

`我抓到机会了，这人马上就要死。`

所以普通敌人的落地原则应该是：

- `势薄`
- `头部命中非常值钱`
- `逼出一次格挡或闪避就已经在明显推进`
- `破势后要很快给处决结果`

也就是说，普通敌人不该让玩家感觉在做复杂对招，而应该像这样：

- 头部中一击，直接接近致命或立刻处决
- 正面被挡住，不算白打，因为你在拆他的势
- 他被逼出闪避，也不算空，因为他已经在交命

普通敌人的理想节奏是：

- 第一手读对
- 第二手逼出反应
- 第三手取命

这样保住的爽感不是“我多砍了几刀”，而是：

`我一旦打准了，他就会死得很利落。`

### 9.6 破势在精英敌人身上怎么落地

精英敌人不能只是“更厚的普通敌人”，不然就会落回普通的两三刀磨杀。

精英敌人的正确设计应该是：

- `势比普通敌人厚`
- `会更明确地格挡、闪避、回身`
- `要逼他连续犯两次防守反应，才会真正散架`
- `一旦破势，仍然要死得很快`

精英敌人的玩法重点不是“多砍几刀”，而是：

`我要怎么把他的保命动作逼出来，再抓他失势的那一拍。`

更具体地说，可以是这种感觉：

- 第一手逼他格挡
- 他还稳得住
- 第二手再逼他闪
- 他的架子开始散
- 第三手追头或者断息跟进
- 这时候他就该进入真正可杀状态

所以精英敌人的体验不是“耐打”，而是：

`更会活，但一旦活不住，就也会死得很惨。`

这是重要边界。精英可以更难杀，但不能更像海绵。

### 9.7 破势在 Boss 身上怎么落地

Boss 身上的破势，不应该只是“更厚一点的势”，而应该成为整场战斗的骨架。

Boss 战推进的真正逻辑不是掉血，而是：

- 我先顶住他的压势
- 我逼他交出防守反应
- 我终于把他的架子拆开
- 我抓住那个真正能伤到他的窗口
- 我再把这几次重创积累成最后的斩决

所以 Boss 的破势落地应该是：

#### 9.7.1 平时能打到，但不算真推进太多

平时不是完全不能碰 Boss，但随便蹭到一刀，不应该等于“我已经打掉他一大截”。

玩家要明白：

`我碰到他了`

不等于：

`我真正拆到他了`

#### 9.7.2 头部命中是大推进，但不会直接结束

Boss 被打中头部，必须是非常值钱的事，因为这是已经定下来的关键机制。

所以头部命中对 Boss 的意义应该是：

- 快速破势
- 明显打乱 Boss 当前节奏
- 强化接下来那一拍的重创机会

但它不能变成“摸到头就直接结束”。

#### 9.7.3 格挡和闪避是玩家推进 Boss 的真实手段

Boss 的格挡和闪避，不该只是“他又躲掉了”。

正确体验应该是：

- 你逼他格挡，说明你已经压到他不得不接
- 你逼他闪避，说明你已经压到他不得不退
- 这两件事都应该算推进

玩家心里应该形成这个判断：

`他在挡，但不是没亏。`
`他在躲，但不是没乱。`

#### 9.7.4 Boss 破势后必须进入“真空期”

一旦 Boss 真正破势，玩家必须清楚知道：

`现在就是能伤到他的那一拍。`

这时候应该有非常明确的变化：

- 身形散
- 节奏断
- 防守空门开
- 受击演出变重
- 音效和镜头都告诉你“这不是普通擦伤”

如果破势后还只是继续普通对砍，这套系统就塌了。

### 9.8 破势后的处决窗口

我们已经定下“破势不是普通削血”，那破势后的处决窗口就必须足够明确，不然玩家会感到自己明明拆开了局，却没有真正拿到结果。

这一段最重要的目标是让玩家明白：

`我现在不是普通打中了。`
`我现在是终于拿到命了。`

#### 9.8.1 普通敌人的处决窗口

普通敌人的破势窗口应该非常短，也非常直接。

原则是：

- 一旦明显破势，普通敌人几乎立刻进入可处决或接近致命状态
- 玩家如果这一拍跟上，结果就应该干脆利落
- 玩家如果错过，也不该把战斗拖很久，而是很快回到“再逼一次就能死”的状态

普通敌人的破势价值应该更接近：

`我拆开你了，所以你马上就得死。`

#### 9.8.1.1 倒地敌人的直接处决

按势能分层，`原地下 + X` 对倒地敌人的结算是：

- `≥ 2层势敌人`：掉2层势，回到常规对抗状态
- `< 2层势敌人`：直接死亡，不留机会

这个结算的核心意义是：

`普通小兵倒地就该死，精英敌人即使倒地也还有喘息机会。`

它保住了两个体验要点：

- `击杀快感`：小兵处决毫不犹豫，玩家爽感直接
- `对抗意义`：精英即使被放倒，处决也只是掉势，维持了战斗的推进感而非终局感

实施的关键约束是：敌人的势能值必须在设定和编程时清晰赋值，1层和2层之间没有灰色地带，这样玩家才不会出现"为什么这次处决没死"的困惑。

在输入与手感层面，第一版进一步确认以下规则：

- `严格条件触发`：`原地下 + X` 只对 `倒地目标` 成立，不和站立失衡、普通破势硬直混用
- `近身小吸附`：玩家需要贴近目标，但允许一个极短的朝目标修正，不做中距离自动吸附
- `目标选择`：附近有多个倒地目标时，按 `摇杆朝向优先，再按距离兜底`
- `命中收尾`：处决命中后进入 `短硬直后可取消` 的收势节奏，既保住分量，也不把战斗流锁死

第一版里，普通敌人和普通精英不具备“临门闪掉地面处决”的能力；只有 `Boss + 少数高阶精英` 可以反应并 `原地闪避` 这一下。这里不做额外的判定丢失分支，而是统一成 `动作照常出手，只分命中与不命中`。如果这类敌人成功闪掉：

- `空间交换`：敌人后撤 `半步到一步`，玩家原地落空收势，双方仍留在同一轮近身对抗里，但已脱离立即处决距离
- `玩家代价`：玩家承受 `短暂落空硬直`；第一版暂不开放取消，后续如引入身法进阶系统，再讨论是否作为增强项有限开放
- `敌人代价`：高阶精英 `掉 1 个完整势豆`，Boss `掉一小截明确势条`
- `反馈方式`：用 `闪避演出 + 明确掉势反馈` 告诉玩家“这次没斩成，但不是白打”

#### 9.8.2 精英敌人的处决窗口

精英敌人的窗口应该比普通敌人更清楚、更值钱，但也更需要玩家抓。

原则是：

- 破势后出现一个明确的短窗口
- 窗口期间，玩家可以用追头、压斩、断息衔接或处决动作把结果坐实
- 如果玩家抓住，精英就该迅速出结果
- 如果玩家错过，精英会恢复部分势，但不该完全回到满状态

这很重要，因为精英的战斗体验应该是：

`你终于把他活路逼没了。`

而不是：

`你只是暂时把他打停了一下。`

#### 9.8.3 Boss 的处决窗口

Boss 的窗口不应该等同于“直接死”，而应该分成两个层级：

- `重创窗口`
你终于真正伤到他了。
- `最终斩决窗口`
你终于走到了最后一刀。

也就是说，Boss 一次破势后通常先进入的是 `重创窗口`，而不是直接终局。

这个重创窗口的意义是：

- 让玩家清楚知道自己这轮推进不是白打
- 让 Boss 身上留下真正的战斗后果
- 把整场战斗从“拆架子”推进到“留伤口”

最终斩决窗口则只会在前面几轮重创累积后出现。

#### 9.8.4 窗口错过时怎么处理

破势窗口最怕两个极端：

- 错过就彻底白打
- 错过也没代价，随便还能继续磨

更合适的处理方式是：

- 普通敌人：错过后仍然很脆，很快还能再收
- 精英敌人：恢复部分势，但不会完全回满
- Boss：重新稳住一部分架子，但会保留已经造成的重创结果

这样玩家会觉得：

`我错过了这一拍，很亏。`

但不会觉得：

`我前面全白打了。`

#### 9.8.5 窗口时长的体感原则

第一版先不锁具体秒数，但体感必须分清：

- 普通敌人窗口最短，像电光石火
- 精英敌人窗口清楚但仍然紧
- Boss 重创窗口略长于精英，但因为压力更高，所以体感仍然很险
- 最终斩决窗口最明确，必须让玩家知道“这一刀就是结尾”

### 9.9 三类敌人的差别，不是血量差，而是交换次数差

更推荐的统一理解方式不是：

- 普通敌人 1 血
- 精英敌人 3 血
- Boss 10 血

而是：

- `普通敌人`：1 次关键读对，很快出结果
- `精英敌人`：2 到 3 次有效压迫，出结果
- `Boss`：多轮压势、破势、重创，最后才到斩决

这样玩家感受到的就不是“耐久不同”，而是：

`活法不同。`

这很重要，因为武侠味更多来自“活法”和“架势”，不是来自数字。

### 9.10 玩家界面怎么反馈“我正在拆他的势”

这里最怕两种错误：

- 完全不提示，玩家不知道自己到底有没有推进
- 提示太像传统血条，战斗立刻掉味

所以建议用 `分层反馈`。

#### 9.10.1 普通敌人：尽量不用常驻 UI

普通敌人不建议挂完整势条，不然屏幕会很乱，也会太游戏化。

更适合普通敌人的反馈是：

- 头顶瞬时点闪
- 身体失衡
- 格挡发颤
- 闪避变狼狈
- 短促清脆的“势裂”音效

也就是说，普通敌人的反馈要像你“看出来他快不行了”，不是靠读条。

#### 9.10.2 精英敌人：用简洁的头顶“势点”

精英敌人适合用克制一点的头顶标记，比如 `2 到 3 个小势点`。

这些点的语义不是血量，而是：

- 当前还能稳住几次关键防守反应
- 或者还有几层架子没被拆开

推荐的读法：

- 点亮：还稳得住
- 破裂：这一层势已经散了
- 全灭：进入真正可杀状态

这样好处是：

- 玩家一眼知道这个精英不是普通人
- 玩家知道自己刚才那一下不是白打
- 它看起来仍然像“架势标记”，不是传统血条

#### 9.10.3 Boss：单独的“势条 / 势环 / 斩决标记”

Boss 的反馈必须比普通敌人更清楚，因为整场战斗骨架都在这里。

但不建议做成普通长血条，更适合的是：

- Boss 名字下方一条 `势条`
- 或者角色周围一圈 `势环`
- 再配合 `重创标记` 或 `斩决刻痕`

也就是把 Boss 的推进拆成两层：

- `势`：现在的架子还剩多少
- `重创 / 斩决`：你已经真正伤到他几次

这样玩家会明白：

我不是在磨一根条，而是在先拆架子，再留伤口，最后等那一刀。

### 9.11 演出上怎么让玩家“感觉到自己在拆势”

演出比纯 UI 更重要，因为这套战斗的味道很大一部分就在这里。

建议把破势反馈分成四种层级：

#### 9.11.1 头部命中

重点是“打到了命门”。

表现可以是：

- 头部后仰
- 身体失衡明显
- 音效更尖、更脆
- 短时间镜头或时间感微顿

让玩家立刻觉得：

`这一击很重。`

#### 9.11.2 格挡被逼出

重点不是“挡住了”，而是“挡得很吃力”。

表现可以是：

- 武器震开
- 手臂压低
- 足下滑退
- 金属爆点更闷、更沉

让玩家觉得：

`他虽然接住了，但已经在硬扛。`

#### 9.11.3 闪避被逼出

重点不是“他又躲了”，而是“他被逼得必须躲”。

表现可以是：

- 闪避动作更急
- 落地更狼狈
- 拉开距离时架子更散
- 呼吸或衣摆音更急

让玩家感觉：

`他不是从容闪过去的，他是在保命。`

#### 9.11.4 真正破势

这是最重的一层，必须和普通受击明显分开。

表现应该包括：

- 姿态彻底散掉
- 明显的硬直窗口
- 更重的镜头、音效和打击停顿
- 角色轮廓或关键部位出现“势裂”视觉标记

玩家要在这一瞬间完全明白：

`我拆开他了。`

### 9.12 最重要的一条边界

这整套机制成不成立，最后看的是这件事：

玩家在连续攻击、逼挡、逼闪、打头的时候，心里会不会一直有推进感。

如果玩家经常觉得：

- “我是不是白打了？”
- “他挡了就等于没事？”
- “他闪了就等于没亏？”
- “我到底什么时候才算真的压到他？”

那这套系统就还没做对。

如果做对了，玩家会一直感觉：

`我在逼他。`
`我在拆他。`
`他快稳不住了。`

### 9.13 Boss 可以不同，但不能乱

这套机制的核心原则是：

`每个 Boss 的打法都应该不同，但每个 Boss 都必须让玩家感觉自己仍然在玩《武侠零》这套战斗。`

可以不同的部分：

- 韩断山靠硬架子撑住
- 杜见潮靠滑、脏、借场
- 叶惊秋靠镜像读招
- 裴霆靠纪律和压迫
- 顾承钧靠最终镜像判断

不能乱变的部分：

- 玩家必须看得懂自己是否推进了 Boss
- 玩家必须知道 Boss 现在是不是失势了
- 玩家必须知道这一刀是不是“真伤到了他”
- 玩家必须知道离最终斩决还有多远

如果这套反馈不统一，玩家就会乱。

## 十、调参与验收标准

### 10.1 调参原则

- 不靠堆血增加难度
- 不靠满屏堆怪增加压迫
- 不让能力变成自动解题按钮
- 要让玩家通常知道自己为什么死
- 要让成功路线一旦跑顺就特别爽
- 敌人的危险主要来自职责组合和时间差，而不是单体耐打
- 破势反馈必须清楚，破势窗口必须够狠

### 10.2 坏战斗的典型征兆

- 敌人太肉
- 正面莽也能稳定赢
- 房间第一眼看不懂重点
- 开局处理对了，后面自动通
- 尾段只剩拖沓清怪
- 特殊能力把所有问题都直接解掉
- Boss 的底层规则每次都断裂，让玩家像在反复学新系统

### 10.3 成功标准

如果玩家打完一个房间后会说出下面这些话，说明战斗方向是对的：

- “我知道刚才错在哪了，我再来一次。”
- “这间房路线打顺特别爽。”
- “我这次是靠判断和执行过的，不是靠运气过的。”
- “我差点死在中间那一下，但还是杀出来了。”

如果玩家打完一个 Boss 后会有下面这些感觉，说明 Boss 结构是对的：

- “我终于杀到他面前了。”
- “我知道自己是怎么拆掉他的。”
- “这一刀很重，不是随便蹭死的。”
